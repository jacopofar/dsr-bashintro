# Bash / Linux command line slides

These are the slides for the Bash/Linux command line course.
The course is by its nature very hands-on, the slides are to help but this is a topic that you learn by doing.
Like other lessons these slides use [Slidev](https://github.com/slidevjs/slidev), this repository contains the
source which is essentially a Markdown file at [slides.md](./slides.md).

To start the slide show:

- `pnpm install`
- `pnpm dev`
- visit <http://localhost:3030>

Edit the  to see the changes. You can generate a PDF using `npm run export`
